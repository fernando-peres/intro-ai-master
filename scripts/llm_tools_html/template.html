1aConcept

What are tools?

A tool is a function in your program that you describe to the model: a name, a purpose and the arguments it takes. The model never runs anything. It can only reply with a structured request. Your code runs the function and sends the result back.

MThe model
decides what to call
  • Reads tool names and descriptions, never the Python code
  • Picks a tool and fills in the arguments from the question
  • Writes the final answer from the returned result
model → your code{"name": "get_temperature",
 "arguments": {"city": "Lisbon"}}
your code runs it
your code → model{"temperature_c": 20.5, …}
CYour code
decides whether & how it runs
  • Owns the actual function (APIs, databases, side effects)
  • Validates arguments, catches errors, checks permissions
  • Sends the result back as a function_call_output
!
The key idea: the model decides what to call. Your code decides whether and how it runs.
