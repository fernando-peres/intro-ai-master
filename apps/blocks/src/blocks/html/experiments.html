Before it reaches customers, it has to win on the same test.

Harbor Cycles, a made-up bike shop, wants to ship a new prompt (v13), maybe a cheaper model, and an agent that looks up orders. Instead of trusting a demo, the team runs experiments: the same test cases, the same checks, several versions side by side. Press Run experiment, then read the Insights tab.
