# Demo, Prototype, Product, and Production

## In one sentence

These stages answer different questions: can AI do it, can it work for us, does it solve a real user problem, and can the institution depend on it?

## The progression

| Stage | Main question | Typical evidence |
| --- | --- | --- |
| Demo | Can the capability appear to work? | Selected examples |
| Prototype | Can it work on realistic cases? | Representative data and early workflow |
| Product | Do users obtain meaningful value? | Adoption, usability, and outcome evidence |
| Production system | Can we depend on it? | Reliability, security, evaluation, integration, monitoring, support, and economics |

## Executive mental model

```text
Demo -> Prototype -> Product -> Production -> Scale
 wow      evidence     value      dependable      sustainable
```

Each transition adds evidence and institutional obligations. A demo may use manually selected data and close supervision. A production system must handle ordinary, difficult, and unexpected conditions repeatedly.

## Why executives should care

GenAI makes demonstrations unusually fast and persuasive. This can create premature confidence. Funding and communication should identify the stage honestly and avoid treating technical possibility as a proven business case.

## Questions to ask

- What exactly has been demonstrated and under which conditions?
- Were cases selected by the project team?
- Which production requirements remain untested?
- What evidence is needed for the next stage gate?
- What would cause us to stop rather than scale?
