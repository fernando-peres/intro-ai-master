# AI Initiative Lifecycle

## In one sentence

The AI initiative lifecycle is the sequence of evidence and operating decisions from problem discovery through retirement, with continuous evaluation and governance.

## Executive mental model

```text
Discover -> Prioritize -> Prototype -> Pilot -> Operate -> Scale -> Retire
    ^           |           |         |         |        |
    +-----------+-----------+---------+---------+--------+
             measure, learn, govern, and decide
```

The stages are not merely technical. Each should reduce uncertainty about user need, business value, technical feasibility, risk, adoption, and economics.

## Decision gates

| Gate | Executive decision |
| --- | --- |
| Discovery | Is this problem worth investigating? |
| Pilot | Is there enough evidence for controlled real-world testing? |
| Operation | Can the institution depend on it in a bounded setting? |
| Scale | Is broader use valuable, controlled, and sustainable? |
| Retirement | Has value declined, risk changed, or a better alternative emerged? |

Valid outcomes at every gate are stop, redesign, continue with conditions, or advance.

## Why executives should care

AI behavior, vendors, data, regulation, and user practice change. Approval is therefore not a one-time event. Accountability continues after deployment and includes safe modification and retirement.

## Questions to ask

- Which uncertainty is this stage designed to reduce?
- What evidence and threshold govern the next decision?
- Who owns the system after launch?
- Which changes require renewed approval?
- What are the pause and decommissioning triggers?
