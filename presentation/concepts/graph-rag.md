# GraphRAG

## In one sentence

GraphRAG augments generation with graph-structured knowledge so retrieval can use entities, relationships, paths, communities, and corpus-level structure rather than only similar text passages.

## Executive mental model

```text
Documents and records
      -> extract entities, relationships, and claims
      -> construct or connect a knowledge graph
      -> preserve links to source evidence
      -> retrieve a neighborhood, path, or community summary
      -> generate an answer grounded in graph + source text
```

## Where it differs from standard RAG

Standard vector RAG is good at questions resembling a relevant passage. GraphRAG can help when the answer depends on connections distributed across sources.

| Question type | Likely retrieval fit |
| --- | --- |
| "What does policy X say about leave?" | Standard or hybrid RAG |
| "How are supplier A, incident B, and product C connected?" | GraphRAG |
| "What are the major themes across this document collection?" | GraphRAG with community summaries |
| "Which source should I search next?" | Agentic RAG |

GraphRAG and agentic RAG are orthogonal. An agent can use graph search as one of several retrieval tools.

## Graph construction choices

- **Curated graph:** experts define entities, relations, and validation rules.
- **AI-extracted graph:** models infer entities and relations from unstructured text.
- **Hybrid graph:** curated ontology and systems-of-record data are combined with extracted claims.

Every edge is a claim that needs provenance, time, confidence, ownership, and correction. A graph generated by an LLM can contain extraction errors and should not be mistaken for verified institutional truth.

## Trade-offs

Potential benefits include multi-hop retrieval, relationship-aware answers, explainable paths, and corpus-wide synthesis. Costs include graph extraction, entity resolution, ontology design, indexing, updates, graph evaluation, and potentially expensive queries.

## Questions to ask

- Which questions fail with simpler keyword, semantic, or hybrid search?
- What are the important entity and relationship types?
- Is the graph curated, extracted, or hybrid?
- How are duplicate entities, conflicting claims, time, and provenance handled?
- What is the cost of indexing and updating the graph?
- How will graph quality and answer quality be evaluated separately?
