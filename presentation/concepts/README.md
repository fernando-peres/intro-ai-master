# AI for Executives - Concept Library

This library expands the concepts in the [course structure](../brainstorm/2026-09-25-silver-structure.md) into short, standalone executive briefings.

Each briefing answers five questions:

1. What is it?
2. How should an executive think about it?
3. Why does it matter to the institution?
4. What should an executive ask?
5. Where can the concept be studied further?

The files are designed for class preparation, discussion, project work, and later reference. They explain enough technology to support judgment without attempting to teach implementation.

## One-page system map

```text
INSTITUTIONAL NEED
       |
AI capability + target workflow
       |
Users / channels
       |
Application, workflow, or agent
       |
Context + knowledge + ontology + memory + skills + tools
       |
Foundation model / ML model
       |
Data + documents + enterprise systems

Across the system:
evaluation | guardrails | human oversight | security | monitoring | governance

Across the initiative:
value | economics | adoption | lifecycle | accountability
```

## Source policy

The briefings favor primary research, official documentation, standards bodies, regulators, and established public-interest guidance. Vendor sources are used when they provide especially clear technical or operating explanations; they are not endorsements of a product.
