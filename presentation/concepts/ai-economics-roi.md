# AI Economics and ROI

## In one sentence

AI economics compares realized institutional value with the complete lifecycle cost and risk of creating, adopting, operating, and changing an AI-enabled workflow.

## Executive mental model

```text
Eligible volume
x improvement per case
x actual adoption
x benefit realization
= gross value

Gross value
- build/buy and integration
- data, evaluation, controls, and change
- inference, infrastructure, support, and incidents
- risk and switching costs
= risk-adjusted net value
```

## Cost categories often missed

- data cleanup and permissions;
- integration with existing systems;
- evaluation and red-team work;
- security, privacy, legal, and compliance;
- user training and process redesign;
- monitoring, support, and incident response;
- model/API consumption at realistic volume;
- vendor management and exit; and
- ongoing re-evaluation after changes.

## Value disciplines

Usage is not value. Time saved is not automatically cash saved. State how released capacity improves throughput, service, quality, revenue, risk, or workforce experience. Use a baseline and credible comparison.

## Questions to ask

- Which business KPI changes if this succeeds?
- Is value measured per license, request, completed task, or outcome?
- What adoption and realization rates are assumed?
- What happens to unit cost at scale and with longer contexts or agent loops?
- Which costs remain if the project stops?
