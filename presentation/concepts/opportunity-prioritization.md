# Opportunity Prioritization

## In one sentence

Opportunity prioritization compares AI ideas using evidence about strategic value, user desirability, technical feasibility, risk, readiness, and time to learning.

## Executive mental model

```text
VALUABLE?     Does it improve an important outcome?
DESIRABLE?    Will users adopt the redesigned workflow?
FEASIBLE?     Can it work with available data, systems, and skills?
RESPONSIBLE?  Can risk remain within tolerance?
TESTABLE?     Can the hardest assumptions be tested quickly?
```

## Suggested dimensions

| Dimension | Evidence sought |
| --- | --- |
| Strategic alignment | Named priority and accountable sponsor |
| Value | Baseline, target, volume, and mechanism of benefit |
| User desirability | Observed need and adoption readiness |
| Data/context readiness | Accessible, permitted, relevant, quality sources |
| Technical feasibility | Model, integration, reliability, and skills fit |
| Risk manageability | Known impacts, regulation, safeguards, and oversight |
| Time to evidence | Bounded pilot that tests critical assumptions |
| Reuse | Shared capability that benefits other initiatives |

## Portfolio principle

Scoring supports discussion; it does not replace judgment. A legal prohibition, unacceptable impact, or critical unknown can override a high average. Confidence in the score should be visible.

## Questions to ask

- Are we comparing business problems or fashionable technologies?
- Which assumption could destroy the case?
- Are resources concentrated enough to produce measurable outcomes?
- Which projects should stop to release capacity?
- Does the pilot test the hardest step or only the easiest demo?
