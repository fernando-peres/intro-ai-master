# AI Capabilities

## In one sentence

AI capabilities describe what a system can do, independently of a particular product or department.

## Capability map

| Capability | Typical output | Example |
| --- | --- | --- |
| Understand | Interpretation or classification | Detect intent in a request |
| Extract | Structured fields | Read invoice number and amount |
| Search / retrieve | Relevant information | Find applicable policies |
| Summarize | Compressed representation | Summarize a case file |
| Generate | New content | Draft a response or image |
| Transform | Rewritten representation | Translate or restructure text |
| Predict | Estimated outcome | Forecast demand or failure |
| Recommend | Ranked options | Suggest next best action |
| Reason / plan | Analysis or steps | Compare alternatives under constraints |
| Converse | Natural-language interaction | Guide a user through a process |
| Act | System operation | Update a case through an API |

## Executive mental model

```text
Business workflow
      -> tasks and decisions
      -> capabilities needed
      -> suitable technology and controls
```

Starting with capabilities avoids the weak requirement "we need a chatbot" and reveals that a customer-service workflow may need understanding, retrieval, recommendation, generation, and a bounded action.

## Questions to ask

- Which capability changes the outcome rather than merely adding novelty?
- Must the output be exact, creative, explainable, or current?
- Does the system assist, recommend, decide, or act?
- Which capabilities require generative AI, traditional ML, or ordinary software?
