One plug, many systems. The model asks; your software decides and runs.

The Model Context Protocol (MCP) is an open standard, introduced by Anthropic in 2024, for connecting AI applications to tools and data. It does not make the model smarter: it changes its reach. Each tab shows one idea from the notebook, with the same model and question, with and without MCP.
